# twemoji-country-flags.woff2

A font holding only flag emoji, served to browsers that draw none (Windows).
See `src/lib/flag-font.svelte.ts`.

Taken unchanged from `country-flag-emoji-polyfill` 0.1.10 by TalkJS
(https://github.com/talkjs/country-flag-emoji-polyfill).

The flag artwork is from Twemoji (https://github.com/twitter/twemoji), used and
redistributed under Creative Commons Attribution 4.0 International,
https://creativecommons.org/licenses/by/4.0/. The site credits it in the footer
on the browsers that use the font.
